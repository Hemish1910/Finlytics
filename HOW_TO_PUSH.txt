┌──────────────────────────────────────────────────────────────────────┐
│                                                                      │
│  What the script does for you:                                      │
│                                                                      │
│  ✅ Creates a branch called "main"                                  │
│  ✅ Adds all your files                                             │
│  ✅ Commits (saves) your changes                                    │

╔══════════════════════════════════════════════════════════════════════╗
║                                                                      ║
║  📝 OR - If You Want to Do It Manually:                             ║
║                                                                      ║
║  Copy and paste these 4 commands (one at a time):                   ║
║                                                                      ║
║  1️⃣  git checkout -b main                                           ║
║     (Creates a branch called "main")                                ║
║                                                                      ║
║  2️⃣  git add .                                                       ║
║     (Selects all files to save)                                     ║
║                                                                      ║
║  3️⃣  git commit -m "Deploy Finlytics to GitHub Pages"               ║
║     (Saves the files with a note)                                   ║
║                                                                      ║
║  4️⃣  git push -u origin main                                        ║
║     (Uploads to GitHub)                                             ║
║                                                                      ║
╚══════════════════════════════════════════════════════════════════════╝
